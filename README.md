# BlackFox AI Workstation

**BlackFox AI Workstation** — самостоятельная веб-платформа для управления кластером локальных LLM-серверов. Один хаб объединяет OpenAI-совместимые серверы, например LM Studio, llama.cpp, Ollama и vLLM, через общий веб-интерфейс.

Проект находится в разработке. Перед подключением рабочих узлов или конфиденциальных данных изучите настройки безопасности и проверьте проект в изолированной среде. Поддерживаемый продукт — веб-платформа и PWA; нативное приложение для рабочего стола не входит в текущую версию.

## Возможности

- Маршрутизация чатов на один узел, все узлы, конвейер, гибридный план или консилиум.
- Управление моделями, ролями, настройками генерации и ветками чатов.
- Телеметрия узлов через необязательный агент.
- Адаптивный веб-интерфейс, который можно установить как PWA.
- Парольная авторизация, роли пользователя и администратора, подпись команд узлам, одноразовые ключи установки, сетевые ограничения и TLS.

## Быстрый запуск

Требуется Python 3.10 или новее. Основные модули используют стандартную библиотеку Python.

```bash
python hub_server.py 8765
```

На компьютере с хабом откройте http://127.0.0.1:8765/ и задайте пароль администратора, а при необходимости — отдельный пароль пользователя. Далее откройте **Настройки → Узлы**, замените адреса-заглушки на адреса своих серверов инференса и выберите модели. Узлы node_1 и node_2 по умолчанию указывают на 127.0.0.1:1234 и 127.0.0.1:1235; сами серверы они не запускают.

Чтобы собирать телеметрию другого компьютера, администратор создаёт одноразовую команду установки агента в интерфейсе хаба. Запустите её на нужном компьютере и оставьте агент доступным только по доверенной частной сети. Не открывайте хаб или агент напрямую в интернете.

## Проверка

Для тестов установите pytest и выполните из корня проекта:

```bash
python -m pip install pytest
python -m pytest
```

Некоторые проверки агента рассчитаны на Windows. Наличие тестов в репозитории не означает, что текущая версия прошла их: запускайте проверки для нужного коммита. CI для этой чистой копии пока не настроен.

## Данные и конфиденциальность

Хаб сохраняет настройки, переписки, учётные данные, сертификаты, загруженные файлы и журналы в папке data/; по умолчанию она исключена из Git. Защитите эту папку и резервные копии. Запросы и вложения передаются выбранному inference-серверу; используйте только серверы, которым доверяете. Дополнительный веб-поиск может получать страницы сторонних сайтов.

Используйте частную сеть, включённую парольную авторизацию и HTTPS с доверенным сертификатом при подключении с других устройств. Перед запуском агентов проверьте сетевые ограничения. Не используйте публичный интернет как сеть для хаба и узлов.
