👥 Подключённые устройства Адрес для подключения:

Интерфейс

Хранится в браузере этого устройства.
Остальные разделы настроек доступны только администратору (интерфейс, открытый на хост-машине кластера).

Узлы

Адрес inference-сервера (OpenAI-совместимый), модель, телеметрия и таймаут каждого узла. Источник телеметрии «авто»: узлы на этой машине — локально, удалённые — агент node_agent.py на порту агента.

Параметры LLM по умолчанию

Используются для всех запросов, если не переопределены skill'ом или параметрами композера.
LM Studio: none отключает «думание» у Qwen3
Сколько предыдущих пар вопрос-ответ передавать узлу
Сколько текста результата этапа передавать следующему

Конвейер по умолчанию

Шаги режима «Конвейер». Каждый шаг получает исходную задачу и результаты предыдущих шагов. В любой ветке конвейер можно скопировать в «Гибрид» и изменить только для неё.

Консилиум

Узлы пишут черновики, затем обсуждают их (раунды критики), модератор собирает один итоговый ответ.
0 — сразу синтез из черновиков
Пусто — целевой узел из композера

Skills — режимы ответа

Skill добавляет инструкцию к системному промпту, переопределяет параметры генерации и может включать поиск в интернете. Встроенные можно подстроить (сброс — «По умолчанию»), свои — добавить.

Подключение, телеметрия, доступ

Задаётся при запуске: python hub_server.py 8765
На узле: python3 node_agent.py 8766
Если агенты запущены с --token
0 — не измерять
Какая LLM переводит команду на естественном языке в действие. Пусто — сам целевой узел.
